# Downloader v0.2.0 — packs de séries, plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** un lien vers une archive `.zip` ou `.rar` contenant une série est téléchargé, extrait,
et chaque épisode est rangé comme s'il avait été collé seul.

**Architecture :** le pack reste une seule ligne de `files`. L'analyse le reconnaît à son extension
et lui donne le dossier `series/<Nom>`. Après téléchargement, `queue.finish` confie le `.part` au
`finisher`, qui le lit avec le nouveau paquet `archive`, range chaque vidéo d'après
`naming.PackDest` et écrit le bilan dans `files.meta`.

**Tech Stack :** Go 1.26.4, `archive/zip`, `github.com/nwaples/rardecode/v2` v2.4.5 (nouvelle
dépendance, accordée), Angular 22.

**Spec :** `docs/superpowers/specs/2026-10-31-packs-design.md`.

## Contraintes globales

- Docs, commentaires et messages d'erreur en français ; identifiants en anglais. Commits
  Conventional Commits sur `release/v0.2.0`.
- Aucune autre dépendance que `rardecode/v2`. Le dépôt est public : ni projet tiers, ni hôte, ni IP
  dans le code, les tests ou la doc.
- Toute destination passe par `naming.Within` avant écriture. Rien n'est jamais écrasé par un pack.
- Messages exacts : « Archive protégée par mot de passe », « Archive illisible : <détail> »,
  « Aucune vidéo dans l'archive », « Espace insuffisant pour extraire », « Extraction : <détail> ».
- Extensions vidéo : `.mkv .mp4 .avi .m4v .ts` ; pack : `.zip .rar` ; comparaison sans casse.
- Mot de passe des archives de test : `fixture-pw`.
- Définition de terminé (avant chaque push) : `task test` à la racine (go vet, go test -race,
  golangci-lint, ng lint, ng build, ng test, puis ng test en `TZ=UTC`).

## Review Focus

1. Pause ou « Retirer » pendant l'extraction : l'extraction s'arrête, `download/<id>/` est supprimé,
   le `.part` reste (test dans la tâche 4).
2. Pack dont toutes les vidéos sont déjà présentes : succès, `placed = 0`, `present = N`, pas
   d'erreur (tâche 4).
3. Archive vide ou sans vidéo (seulement `.nfo`, `.srt`) : « Aucune vidéo dans l'archive » (tâche 4).
4. Extensions en majuscules (`.MKV`, `.RAR`) reconnues (tâche 2).
5. Fichier qui n'est pas une archive malgré son nom (page HTML servie à la place) : erreur lisible
   « format inconnu », pas de panique (tâche 1).
