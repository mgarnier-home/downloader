# Maquettes

Maquettes validées le 31/10/2026, avec des données fictives. Elles tiennent dans `maquettes.html`, une
page autonome à ouvrir dans un navigateur, qui ne charge que Google Fonts (IBM Plex Sans et IBM Plex
Mono).

| Onglet de la page | Contenu                                                                     |
| ----------------- | --------------------------------------------------------------------------- |
| B · Bureau        | **Variante retenue**, en 1280 px. Les onglets de l'application sont cliquables. |
| B · Mobile        | Variante retenue en 390 × 844 : En cours, vérification Vidéos, Musique.     |
| A, C              | Variantes écartées (une seule barre, tableau par étapes), gardées pour mémoire. |

Les règles qui découlent de ces écrans sont dans
`docs/superpowers/specs/2026-10-31-downloader-design.md`.
